## 🔥 **How to Approach These Problems?**
1. **Start with basics** (Problems 1-10) ✅  
2. **Move to two-pointer and cycle detection problems** (Problems 11-20) 🚀  
3. **Practice in-place modifications (reversal, merging, partitioning)** (Problems 21-30) 💡  

Since you're preparing for an **embedded software interview**, you should focus on:  
- **Pointer manipulation** (deleting, inserting without extra memory)  
- **Efficient in-place operations** (O(1) space complexity solutions)  
- **Understanding Floyd's cycle detection**
